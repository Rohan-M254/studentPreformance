# Student Performance Statistics

A Python exercise that analyses the distribution of student reading scores and reports descriptive statistics.

## Project structure

- `c109/studentPreformance.py` — calculates mean, median, mode, standard deviation, and the percentage of scores within one, two, and three standard deviations.
- `c109/studentPreformance.csv` — input dataset.

## Requirements

```bash
pip install pandas plotly
```

## Run

Run from the `c109` directory:

```bash
python studentPreformance.py
```

## Notes

The original plot contains duplicated standard-deviation traces and does not draw the three-standard-deviation interval. The reported percentages are calculated separately. This repository also contains an older copy of the related `c109` exercise; that duplicate is retained for now rather than removed without confirming its history.
